## 重要设计决定

- 默认 4 位专家，另加 1 位主持人；专家 2–6 位是拟定 MVP 范围。
- 专家分别提交短意图，调度器仲裁；只为被选中的专家生成完整发言。
- 独立后台 Runner 负责讨论；SSE 仅订阅。单进程、每讨论唯一任务。
- SQLite 持久化消息、观点和事件；一致快照 + 事件游标补发处理刷新与重连。
- 模型输出 schema 校验、有界重试；真实模式出错不暗中切换成预设文本。
- 共识/分歧持续提炼且验证证据；不展示隐藏推理过程。
- 不做登录、云部署、语音、向量库或复杂任务队列。
