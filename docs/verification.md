## 已观察并修正的问题

- 受限环境内 Vite 监听存在但客户端连接超时，正常网络权限重启后 HTTP 200、浏览器可见。
- 一轮 TestClient 因本地套接字权限挂起；授权环境重跑通过，旧进程清理。挂起那轮不算通过。
- 演示分歧关键词漏匹配，修正并增加种子证据回归测试。
- 前端快照与实时事件可能交错，加入序号防倒退，启动状态由 SSE 驱动。
- 自动跟随改为即时滚动，避免 smooth scroll 的中间事件误判为用户查看历史。
- Windows 的 Vite/esbuild 进程会占用依赖，npm ci 前应先关闭开发服务。首次复现因此失败；2026-11-18 确认无残留进程后重新执行成功。
- 上次自动审批因额度耗尽而未执行安装恢复命令；该事件不代表命令不安全，也没有绕过审批执行。
