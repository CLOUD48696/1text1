## 2. 已修正的问题与验证范围

| 问题 | 修正与验证 |
| --- | --- |
| 服务显示监听但浏览器连接超时 | 重启到可连通的运行环境，确认 HTTP 200 并检查页面 |

## 3. 真实 DeepSeek 验收：待执行

适配器的模拟 HTTP 测试只证明请求构造与响应校验，不证明真实服务可用。按安装指南配置 live 并重启后，完成以下检查：

- [ ] 记录实际模型标识、测试日期、专家人数和话题；不记录 Key。
- [ ] 成功生成符合人数要求、身份与立场合理的阵容。
- [ ] 用户确认后开场，出现相关的补充/反驳与主持人介入。
- [ ] 专家发言保持 1–2 句，页面无隐藏推理或原始 JSON。
- [ ] 讨论过程中出现有真实发言依据的共识与分歧。
- [ ] 完整结束并保存自然语言总结，刷新后内容一致。
- [ ] 记录阵容耗时、首条发言等待、总耗时、失败情况及可获得的实际费用。
